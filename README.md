Verb∋Net - révision
========

Cette version dérivée de la [version originale](https://github.com/aymara/verbenet) a été développée lors de la rédaction d'un article soumis par Marie-Claude l'Homme et Guy Lapalme sur l'utilisation de Verb∋Net pour la génération de texte.

Cette version apporte les modifications suivantes:

-  Ajout du fichier `VERBENET.xml` qui inclut tous les fichiers XML, ce qui permet d'exécuter des requêtes XPath sur l'ensemble des fichiers.

- Ajout d'un schéma RELAX-NG pour valider les fichiers XML 
- Corrections de typos dans certains exemples et verbes membres 
- Corrections de listes de verbes pour s'assurer qu'il n'y a qu'un verbe par élément `MEMBER`
- Corrections de quelques frames ou rôles pour les faire correspondre à l'exemple.
